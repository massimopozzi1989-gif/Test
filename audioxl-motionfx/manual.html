01 — Getting started

Three modules,
four lanes of motion

AudioXL Motion FX applies three effect modules — Filter, Volume, Pan — in parallel, plus drive/noise, an FX rack, a granular engine and beat repeat. The movement comes from four independent sequenced lanes, all synced to the host tempo.

Filter

SVF (State Variable) filter with a logarithmic sweep — ideal for acid sweeps.

Volume

Rhythmic gating — depth sets how far the envelope pulls the volume down.

Pan

Stereo sweep in sync with the rhythm.

First sound in Logic Pro

01Insert

Put AudioXL Motion FX on a channel as an Audio Effect Unit.

02Play

Start playback — the envelope syncs automatically to the project BPM.

03Draw

Shape the envelope by clicking on the 16 bars.

04Switch on

Enable the modules with their ON buttons — Filter is on by default.

02 — Motion sequencer

Four lanes,
one big graph

LaneWhat it isDestinations

All four are edited in the same large graph: the MAIN / SEQ 1 / SEQ 2 / SEQ 3 tabs at the top right of the MOTION SEQUENCER panel switch the lane on display.

Note

SEQ RND randomises the lane you are looking at, not always the main one.

ControlRangeWhat it does
Stepsper barEvery bar is a step. MAIN is unipolar (0–100 %); the SEQ lanes are bipolar (−100 … +100 %) and grow from the centre line.
LEN1 … 16Pattern length. A 7-step lane against a 16-step MAIN makes polymeter — the two only come back into phase after 112 steps.
Swing0 … 75 %Delays the odd step of every pair. Each lane has its own, so you can layer different grooves.
LinearMAIN onlyLinear interpolation between steps.
GlideSEQ onlyPortamento between steps, from hard steps to a full slide.
Lane ONon / offSwitches the lane on or off without leaving the page.
Sync1/32 … 1/4Divides every step into time units (1/16 = one step every sixteenth). For SEQ lanes the division is the length of one step, so the cycle lasts LEN × division.
03 — Randomize

Roll the dice,
keep the seed

Every section has its own randomiser — Filter, Volume, Pan, Beat Repeat, Drive, Noise, the three LFOs, Reverb, Delay, Chorus, Flanger, Granular — plus a global ALL RND. A Seed Lock in each section fixes the random seed, to repeat the same result or vary it step by step.

Envelope sequencer

RND ShapeA new random curve over the 16 steps, with a uniform or weighted distribution: Smooth / Sparse / Dense.
RND SyncPicks a random subdivision among 1/32, 1/16, 1/8, 1/4.
RND ModuleRandomly switches one or more modules on or off (Filter, Volume, Pan).
Seed LockFixes the random seed — useful to repeat the same result or vary it incrementally.
04 — Trigger · envelope sequencer

When the
motion starts

The Trigger module decides when and how the envelope sequencer is started, reset or pulsed. Four selectable sources, which can be combined.

01 · Euclidean

Rhythmic patterns spread euclideanly over N steps.

Steps (N)1 … 32Total steps of the pattern.
Pulses (K)K ≤ NHits spread as evenly as possible over N.
Rotation (R)offsetPattern rotation (0 = canonical position).
Rate1/32 … 1/4…How fast the pattern advances.
N 16 · K 5 · R 0

Classic Björklund pattern.

02 · Clock

Division1/32 … 1 bar1/32, 1/16T, 1/16, 1/8T, 1/8, 1/4, 1/2, 1 bar — synced to the host transport.
Phase offset0 … 100 %Delays the trigger as a percentage of the division.
Reset on baron / offResets the envelope position at the start of every bar.

03 · MIDI

The envelope starts (or is reset) when MIDI notes or CCs arrive.

Note OnchannelTriggers on every Note On on the selected channel.

04 · Transient detector

Analyses the incoming audio and triggers the envelope on the detected attacks.

Sensitivity0 … 100 %Transient detection threshold.
Attackfast / med / slowResponse time of the detector.
Filter band4 bandsLow (kick), Mid (snare/clap), High (hat/perc), Full.
CooldownmsMinimum time between two triggers — avoids double triggers.
Sidechain inputself / ext.Audio source for the detector: the signal itself or an external sidechain bus.

Combining the sources

First

The first source to fire wins — useful for a MIDI override on top of the clock.

AND

Triggers only if two or more sources fire in the same window (±1 step).

OR · default

Any source starts the envelope.

Priority

Manual priority order — drag and drop the sources in the list.

Randomize — trigger

RND EuclideanA new random N/K pair with K between N/4 and N/2 (musical density) and a random rotation.
RND SourceRandomly enables a combination of trigger sources in OR mode.
RND DivisionClock: picks a random subdivision among the synced ones.
Seed LockFixes the seed.

06 — LFO / step generators

Three generators,
27 destinations

Three independent modulation sources, on top of the main envelope sequencer. Each can modulate any parameter through the routing matrix, and each works in two modes: LFO (a continuous waveform) or Step Sequencer (16 steps, the same engine as the main envelope, set up separately).

LFO parameters

Shape9 shapesSINE, TRI, SAW, RSAW, SQR, S&H, BIN, RND, SEQ.
Rate0.01–20 Hz · 1/1–1/32Free frequency, or synced to the BPM.
Syncon / offLocks the rate to the host transport.
Depth0 … 1Modulation amount, applied to the bipolar signal.

SEQ mode

Choosing SEQ as the shape turns the LFO into a 16-step lane. Edit it in the large graph of the MOTION SEQUENCER panel (tabs SEQ 1 / SEQ 2 / SEQ 3); the scope on the LFO page shows the pattern with the playing step highlighted.

LEN1 … 16Lane length in steps.
Swingper laneShuffle inside the lane, independent of the others.
Glide0 … 1Portamento between adjacent steps (0 = steps, 1 = full slide).
Sync divstep lengthThe full cycle lasts LEN × div.
Step values−1 … +1Bipolar: a lane can push the destination above and below the value set by its knob.

Routing matrix

Every LFO/Step can be assigned to one or more destinations at once — 27 of them, chosen from each LFO’s TARGETS button. The indices are stable: new ones are only added at the end, never reordered.

LFO 1

Primary modulation — typically the slowest, the global shape.

LFO 2

Secondary modulation, or in quadrature with LFO 1.

LFO 3

Fast / timbral modulation, or a variation step sequencer.

The three LFOs can be phase-synced or run free, independently.

Randomize — LFO / step

RND LFOPer generator: randomises Shape, Rate (synced), Phase and Depth — keeps Smooth and Retrigger unchanged so the timing stays stable.
RND StepsStep mode: a new random N-step sequence with a Smooth / Sparse / Groove distribution (random swing between even and odd steps).
RND RouteRandomly assigns each LFO to a destination in the matrix, with an Amount between −50 % and +50 %.
RND ALLRandomises all three generators at once while keeping musical coherence — avoids modulation clashes on the same destination.
Seed LockFixes the seed — allows incremental variations of the same random patch.

The step grid

The beat-repeat step grid — Roll, Reverse, Pitch, Stretch, Stop — supports drag-to-merge of columns, with ON/OFF, DRY/WET, RATE and RND. It is covered by undo like every knob, and it is reset by every preset.

09 — Undo and output safety

Undo anything,
hurt nobody

Undo / redo

Two buttons in the header, between SYNC and PREFERENCES — dimmed when there is nothing to undo or redo, white otherwise. The tooltip says what would be undone or redone.

Knobs, toggles, menusOne step per interaction: one knob turn = one undo, not one per pixel of movement.
PresetsFactory and user: loading one is a single undo step, even though it changes ~150 parameters and resets the beat-repeat grid. Loading a user preset keeps the earlier history.
Beat repeatThe step grid, drag-to-merge, ON/OFF, DRY/WET, RATE, RND — all undoable.
RNDPer module, SEQ RND, ALL RND: one click, one undo — even when ALL RND touches ten modules at once.

The history is cleared only when the host reloads the plugin state — that is, when you open a saved project. Never on a preset change during the session.

Output safety ceiling

The output goes through a soft limit: transparent up to 2× full scale, then a knee that never exceeds 4×. It is not an effect and is not meant to be touched — it only makes sure no combination of parameters can slam the monitors of whoever is trying the plugin.

It touches nothing musical: the hottest preset in the library reaches ~3.3× only with an already hot input (the ceiling takes 0.4 dB off that single peak), and every parameter measured on its own from the defaults stays well below.

10 — Activation

Ten minutes,
then one serial

The plugin runs for 10 minutes from first launch — real time, not playback time — then goes into stand-by: the audio comes out muted until a valid serial is entered. The ten minutes are a single budget tied to the machine, not a per-session timer: closing and reopening the plugin or the DAW doesn’t reset it.

The header shows no countdown and no AUTHORIZE button — only a PREFERENCES button, to the left of POWER.

1 · Any time

PREFERENCES › AUTHORIZATION: the demo status (time left, or ACTIVE with the registered serial), the serial field and the UNLOCK button.

2 · At expiry

When the 10 minutes run out the plugin opens the preferences on the AUTHORIZATION tab by itself — once per session, so it doesn’t keep stealing focus. The window can be closed; the audio stays muted until a serial is entered.

TabWhat’s there
GeneralfoldersThe folders the plugin writes to — user presets and authorisation data — each with an OPEN button.
AuthorizationlicenceDemo/licence status, serial field, UNLOCK.
AboutinfoLogo, name, version, company and website — the same screen that opens when you click the logo in the sidebar.
Serial format
AXLM-XXXX-XXXX-XXXX

Upper-case letters and digits; case and dashes don’t matter when typing it.

One activation, every format

Per installed plugin on the machine, not per DAW session: VST3, AU and Standalone share the same state. It survives plugin updates as long as ~/Library/AudioXL/MotionFX/ is not deleted.
